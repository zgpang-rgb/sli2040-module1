SLI 2040 & the Three-Section Framework

Where a live project sits in the SLI 2040 architecture, which section owns it, and how it moves through the Plan-Run-Measure operating loop from problem immersion to validated scale.

Learning outcomes

After this module a learner should be able to:

  1. Place a live project within the SLI 2040 enablers, domains and thrusts, and the MLS Framework 2040 Military Learning Pillars.
  2. Route a solution-first request to the correct section using the architect / materials engineer / construction crew division of labour.
  3. Sort incoming signals into the Learning Science and Learning Technology watch areas.
  4. Diagnose a project stalled between Run and Measure in the Plan-Run-Measure operating loop.
  5. Work the short-cycle loop from problem immersion through controlled trial to validated scale.
  6. Review a draft Trial Implementation Plan against its five components and identify what to return first.
  7. Walk a live project through all six loop stages in the capstone.
